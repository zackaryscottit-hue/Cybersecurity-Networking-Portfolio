# Enterprise Network Security Assessment

## Project Overview

Designed and tested a simulated enterprise network using VMware Workstation, pfSense, Kali Linux, Ubuntu Linux, and Metasploitable2.

The goal was to implement network segmentation, configure firewall policies, evaluate network security, and identify potential vulnerabilities in a controlled lab environment.

## Technologies Used

- VMware Workstation
- pfSense Firewall
- Kali Linux
- Ubuntu Linux
- Metasploitable2
- Nmap
- OpenVAS / Greenbone
- Wireshark
- iperf3

## Project Implementation

### Phase A: Network Baseline
- Established baseline connectivity between virtual machines.
- Captured and analyzed network traffic using Wireshark.
- Examined DNS, ICMP, HTTP, HTTPS, and SSH traffic.

### Phase B: Network Configuration
- Configured pfSense firewall interfaces and network segments.
- Implemented firewall rules to control communication between network zones.
- Troubleshot routing and connectivity issues.
- Tested permitted and blocked network traffic.
- Used iperf3 for network performance testing.

### Phase C: Vulnerability Assessment
- Conducted host discovery using Nmap.
- Performed service and version detection.
- Configured OpenVAS / Greenbone for vulnerability assessment.
- Investigated connectivity and vulnerability scanner configuration issues.
