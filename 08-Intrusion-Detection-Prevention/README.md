
# Intrusion Detection & Prevention (IDS/IPS)

## Project Overview

Implemented and tested network intrusion detection technologies in a controlled virtual lab environment to identify suspicious traffic, analyze security alerts, and improve threat detection accuracy.

The objective was to gain practical experience with network-based intrusion detection, custom security rules, traffic analysis, and alert tuning.

## Technologies Used

- Snort IDS
- Suricata
- Zeek
- Wireshark
- Kali Linux
- Ubuntu Linux
- VMware Workstation
- Nmap

## Project Implementation

### Phase A: IDS/IPS Fundamentals
- Studied network-based intrusion detection and prevention concepts.
- Compared signature-based and anomaly-based detection.
- Reviewed the differences between IDS monitoring and IPS blocking.

### Phase B: IDS Deployment
- Installed and configured Snort in the virtual lab.
- Used Suricata and Zeek in network traffic analysis exercises.
- Captured network traffic using Wireshark and tcpdump.
- Verified that the monitoring tools could observe network activity.

### Phase C: Detection Rules and Alert Analysis
- Created custom Snort detection rules.
- Generated ICMP traffic to test intrusion detection.
- Verified that Snort generated alerts for matching traffic.
- Investigated suspicious network activity and analyzed alert output.

### Phase D: Rule Tuning and Optimization
- Reviewed detection rules for potential false positives.
- Modified rule thresholds and detection conditions.
- Retested network traffic against the updated rules.
- Documented rule tuning and recommended improvements.
